Assets

Assets is the loaded job. Resize, Crop, Bleed, Grid, Booklet, Cutter, Rotate, Color, Mail Merge, and preflight read that list. Each page shows its size. Color pages are labeled Color, Pagemix, or Colormix. Selection covers every page, fronts, backs, one size, or a property match. Pages can move into another PDF. Clearing the asset list leaves the recipe in place.

Page boxes: leave MediaBox, CropBox, TrimBox, and the bleed box, set CropBox to TrimBox so a viewer hides the bleed, or clip to trim and drop the extra margin. When the art already includes bleed, Grid, Booklet, and marks step on finished trim, not the bleed box. Gutter of zero: trims touch, bleed hangs into the gutter, crop marks sit on the trim.

Page setup

Page controls edit the highlighted pages, including a selection that spans files. The file on disk is unchanged until save. Color, crop, bleed, resize, and rotate can be stored before imposition. Resize places from a 3 by 3 anchor with horizontal and vertical offsets, and keeps artwork size unless stretch is on. Rotate is 90, 180, or 270. A quarter turn swaps width and height. Fronts and backs can rotate independently. Blank inserts an empty page for a duplex or booklet back. Delete removes the highlighted page from the working file.

Add to recipe writes those edits as one Page setup line. On the next run that line applies to the files loaded at run time. Arrange is page order: reorder, rotate, recolor, then write the order back. Join combines the loaded PDFs. Split writes each page as its own PDF.

Recipe order

Applied Steps is the stack. Add appends a line. Overwrite replaces the selected line. Click a line to reopen the tool. Working order: grow bleed, then impose, then cutter marks. Convert color before preflight.

Grow bleed is for art with no bleed. Quick grow scales the page. Edge extend mirrors or stretches the outer edge. The grown page keeps a TrimBox, so Grid and Booklet pack on finished size. Grid is step-and-repeat: rows and columns, or auto max-fit, with gutters, margins, and a 3 by 3 anchor. Booklet is saddle-stitch. Creep is the thickness of one sheet. The cover does not shift. Each sheet inside adds that amount again. Cutter marks target every page, fronts, or backs, for a collator or cutter. Folds are a monitor guide, not a production step. Mail merge is the VDP line on the same recipe: a template PDF plus CSV, Excel, or ODS. The saved recipe holds the template, so a hot folder can receive only the spreadsheet.

Preflight profiles

Profiles are editable. Built-in starts: Standard Digital Press, Commercial Sheetfed, and Soft Proof. Checks: image resolution, embedded fonts, trim and bleed boxes, RGB, hairline strokes, total area coverage, transparency, overprint, and JPEG 2000. Each check can fail, hold, or be ignored. The report, JSON or PDF export, and jump-to-fix from a finding are in the product.

Color on the recipe runs before that check. Conversions: original, grayscale, black and white, sepia, CMYK, or RGB. Raster DPI: 300, 400, 600, or 1200. CMYK includes gray-component replacement, a total-ink limit, and per-channel trim.

Production destinations

Extra folders named on the recipe. The save path is unchanged, and a copy is written to each selected folder. The recipe file stores Applied Steps, page setup, the unit, and those folders. One recipe: page setup, Applied Steps, the unit, and the production folders. The next job loads that list.

Questions from the desk

What runs overnight?

Unlimited automation pipelines. Each has an input, an output, and a saved recipe. One watcher runs every pipeline that is filled in. Preflight can route pass, hold, and fail to different folders after the shift ends.

Is there a cap on pipelines?

No. LockStepPDF runs as many automation pipelines as the shop starts, at the same time. LockStepOCR does the same for watch-folder OCR. They are not sold as modules.

Where do the files go?

Onto the prepress PC or the shop server. LockStepPDF and LockStepOCR do not upload the job. There is no account and no shared file-size cap.

What is the LockStepPDF trial?

LockStepPDF installs as a fully functional Pro license. It runs for 30 days from the install date. Every tool is on: prepress, preflight, and unlimited automation pipelines. A commercial seat is one workstation.
