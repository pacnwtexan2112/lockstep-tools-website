The job, not a feature list

Sheets of labels

LockStepLabel is being built for the label work a shop already runs. This page describes that job. It does not describe finished software. There is no version, no installer, and no price.

The sheet

A label job is rarely one label. It is a sheet the press can run, with many labels on it. The sheet has a size. Each label has a finished size. The two are not the same number, and prepress is the gap between them. Until LockStepLabel ships, that gap is still someone else’s step, or a hand-built layout. This page is not offering a tool that closes it yet.

The gutter

Labels on a sheet need space between them. That gutter is how the cutter, or the kiss-cut, separates one finished label from the next. Too tight and the cut wanders into the art. Too loose and the sheet holds fewer labels than the estimate assumed. The gutter is part of the job LockStepLabel is being built for. It is not a control you can set in a program today, because the program is not finished.

The finished size

The finished size is the label after it is cut, not the file the customer happened to export. A shop speaks that size the way it speaks a business card or a page. The art has to land on that size, on a sheet, with a gutter, and with enough room for the marks bindery expects. Describing the job is not the same as shipping the tool.
