How you use it

Stock, type, artwork, then a PDF or a local print.

Set the sheet. Place type and artwork. Read the layout on the sheet preview. Write a PDF, or print at actual size.

  • Stock

    Brand sheets include Avery, including 5160. A custom sheet is a rectangle, a circle, or a triangle.

    Lay the labels out as an even grid, or place each label. A rectangle can carry a corner radius.

    Switch from an even grid to place-each, and the type stays in the same position on each label.

  • Type

    Multiline type. A line can run on every label, or only on the labels selected in the sheet preview. Set the font, the size, and the angle.

  • Artwork

    Place artwork on the label. Scale it. Rotate it.

  • Sheet preview

    The preview is the imposed sheet. Click a label to restrict a line to that label.

  • PDF and print

    Write a PDF of the imposed sheet, or send it to a local printer. Print at actual size. Fit-to-page will scale the sheet off the stock.

Before a full run

Print at actual size.

Print at actual size. Turn off fit-to-page. Check the sheet against the physical stock before a full run.
