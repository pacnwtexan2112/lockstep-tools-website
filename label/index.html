Imposition

Finished size, gutter, sheet

Under development. No version, no installer, no price. The parameters below are the job this program is being built against. They are not controls in a shipping build.

Finished size

Finished size is the label after the cut. Incoming art is one-up. Sheet size is the press sheet. LockStepLabel does not run that imposition yet.

Gutter

Gutter is the space between labels on the sheet, for the cutter or the kiss-cut. It is part of the job the program is being built for. It is not a setting in a program today.

Sheet

Sheet size is what the press runs. Finished size and gutter set how many up, and how much room is left for marks. Until LockStepLabel ships, that layout is done outside this program.

Availability

Nothing on this page is for sale. No installer. No buy button. No price. One-time purchase when it ships. Do not schedule a live job on it.
