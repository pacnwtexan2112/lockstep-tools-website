The pipeline

One master switch. Unlimited pipelines.

Unlimited OCR pipelines, running at the same time. Each has a watch folder, an output folder, a file name, and a post-process action. Output is a searchable PDF at the original page size. The source file is not deleted.

Pipeline 1

Separate watch folder, output folder, prefix, original name, and suffix. The default prefix is Searchable_OCR_. Output is a searchable PDF. The source file remains in the watch folder. Page size is unchanged.

Pipeline 2

Runs while the other pipelines run. Separate watch folder, output folder, prefix, original name, and suffix, so the rename rule does not collide with pipeline 1.

Pipeline 3

Another pipeline on the same night. Separate watch folder and output folder. Same output: searchable PDF, original page size, source file left in the watch folder. Pipelines are unlimited. Add another and it runs with the rest.

Pipelines Unlimited OCR pipelines, running at the same time. Each has its own watch folder and output folder.
Watch folder Folder the pipeline watches for a scan or a flat PDF. LockStepPDF does not need to be open.
Output folder Where the searchable PDF is written. Originals stay in the watch folder.
File name A prefix, the original name, and a suffix, then .pdf. The default prefix is Searchable_OCR_.
Page size The new file keeps the page size of the art. OCR is a text layer, not a reflow.
After processing Post-process action when the file is written. “Do nothing” leaves the PDF in the output folder.
