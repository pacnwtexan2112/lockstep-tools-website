In version 3.54

These are the steps without an asterisk. Add one, reorder the stack, save the recipe.

  • 01

    Resize

    Map a client PDF to Letter, Tabloid, or a width and height you type. Force landscape when the stock is turned. Stretch the art to the bounding box, or leave the aspect ratio and center it. The trim box follows.

  • 02

    Crop

    On import, keep the original boxes, set CropBox to TrimBox, or clip the extra margin back to TrimBox. Preview, export, and the steps you stack all use that choice. Monkey, Grid, and Booklet can impose to the TrimBox instead of the MediaBox.

  • 03

    Rotate

    Turn the page into the orientation the press sheet wants before the next step. It sits with Resize and Crop, which is where orientation problems actually show up.

  • 04

    Cutter

    Crop marks in black or white, with positive or negative overlap so the mark crosses into the trim or sits off it. Cutter L, registration, and dots land on the four corners for Monkey, Grid, and Booklet.

  • 05

    Monkey

    The imposition tab beside Grid and Booklet. Use it when the sheet is not a plain step-and-repeat and not a saddle stitch. It honors TrimBox and takes the same crop marks as the other two.

  • 06

    Grid

    Step and repeat. Set rows, columns, and gutter, then lock a selection so the pieces stay put when the grid changes. A 3×3 white-space anchor pads from the cell you pick. Built for cards, tags, and labels on 12×18 and 13×19.

  • 07

    Booklet

    Paginate a reader file into 2-up printer spreads. Creep is the paper thickness; each inner sheet adds that amount. Outward moves content toward the spine. Inward opens the gutter. The same 3×3 anchor Grid uses can pad the margins.

Marked for Pro

Shown in 3.54 with an asterisk: planned for the Pro tier. Descriptions are the jobs they are being built to run.

  • Mail Merge/Stamp

    Pro

    Variable data, on your hardware

    Open ODS, XLSX, or CSV. Click a column, then the template. Address blocks place, with bold, italic, and underline. Mail merge prints in millimetres, including a tight envelope window. Output pages are template pages times rows that contain data.

  • Color

    Pro

    Color, next to page geometry

    The Color step is where a preflight finding goes when the art is RGB and the press is not. Page Geometry stays in the unit the desk already uses: inches, millimetres, or points.

  • Preflight

    Pro

    A press-side audit

    Fonts, including art inside forms. Resolution at the DPI you set. RGB on CMYK work. Bleed, hairlines, ink coverage, transparency, overprint, and JPEG 2000. The report does not rewrite the file. 3.54 can already note page size, RGB, images under 250 DPI, and font names on screen.

  • Automation

    Pro

    Hot folders and recipes

    Three pipelines. Each has its own input, output, and saved recipe. Drop a PDF and the recipe runs. Drop a spreadsheet on a recipe that already holds the envelope, and it mail-merges. The job waits until the copy finishes, including from a network path.

  • Unlock

    Pro

    Owner passwords off the file

    Strip an owner password and a print-lock so the file can be cropped, imposed, and sent to the RIP without a detour through the program that locked it.

  • OCR Extract

    Pro

    Searchable text, inside this app

    OCR Extract is the in-app step, still marked Pro. The engine that already ships is LockStepOCR: three watch folders, a searchable PDF, original page size. Use that today. This button is the one that will live on the LockStepPDF stack.

LockStepPDF questions

Straight answers, matched to version 3.54.

What is LockStepPDF?

Windows prepress software from LockStep Tools, sold as a subscription. It was ReadySetPDF. Resize, crop, rotate, cutter marks, and imposition run on your own PC. Customer files stay in the shop. The subscription price is not listed on this site.

What is actually in the 3.54 download?

Resize, Crop, Rotate, Cutter, Monkey, Grid, and Booklet. You can stack those steps and save a recipe. Mail Merge/Stamp, Color, Preflight, Automation, Unlock, and OCR Extract are drawn in the window with an asterisk. That asterisk means marked for Pro in this build, not included in this installer. It is a contents note, not the price. LockStepPDF itself is a subscription.

Does it work offline?

Yes. Files are not uploaded to a browser or a cloud queue. There is no file-size cap from a shared server, and a customer list does not have to leave the shop. That matters for healthcare mail and other regulated work.

Can it do variable data?

Mail Merge/Stamp is the tool for ODS, XLSX, and CSV, including address blocks and millimetre placement for envelope windows. It is marked Pro in the 3.54 window, so it is not in the current installer. A hot folder that already holds the envelope is part of that same Automation work.

Does the booklet maker compensate for creep?

Yes. Creep is paper thickness, added for each inner sheet. Outward moves content toward the spine. Inward opens the gutter. Booklet is in the 3.54 download.

What happened to fold proofs, blank pages, and splitting?

They were listed on the old ReadySetPDF page. They are not buttons in 3.54, so they are off the tool grid. That is about this build, not about a free tier.

What preflight checks run today?

3.54 can report page size, RGB, images under 250 DPI, and font names. The fuller press-side audit — bleed, hairlines, ink coverage, transparency, overprint, JPEG 2000, and a saved recipe — is the Pro Preflight tool. The report does not rewrite the file.

Does it understand MediaBox, CropBox, and TrimBox?

Yes. Keep the original boxes, set CropBox to TrimBox, or clip extra margin to TrimBox. Monkey, Grid, and Booklet can impose to the TrimBox.

What are the system requirements?

Microsoft Windows. Version 3.54 installs from a setup file. No browser and no account. The file is still named ReadySetPDF_v3.54_Setup.exe.

How is LockStepPDF sold?

As a subscription. Version 3.54 is the installer available today. This page does not list a price, a billing period, or a place to pay. It is not a free-forever product and it is not a one-time purchase. LockStepOCR is the free tool. LockStepLabel, still under development, will be the one-time purchase.

Where did ReadySetOCR go?

It is LockStepOCR, a separate download. OCR Extract inside LockStepPDF is the Pro step that will sit on this stack later. If you need searchable PDFs now, use LockStepOCR.
